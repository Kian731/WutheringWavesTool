# 鳴潮攻略站（本機網頁版）

版本基準：**3.5（2026-08）**　·　全繁體中文　·　純靜態，**所有圖片都已下載到本機，離線可用**。

## 怎麼開

直接用瀏覽器開 `index.html` 即可（資料用 `<script>` 載入，不是 `fetch`，所以 `file://` 也能跑）。

想用本機伺服器（行為最接近正式網站）：

```bash
node .claude/serve.js
```

然後開 http://localhost:8777

### 資料來源

- **鳴潮 BWIKI**（wiki.biligame.com）MediaWiki API — 主要來源：基本資料、基礎屬性、技能、共鳴鏈、突破素材、武器、聲骸
- **庫街區官方 WIKI**（api.kurobbs.com）— 補齊 BWIKI 尚未填寫的 9 位角色技能與 10 位角色的突破素材
- **wuthering.gg** — 補齊 BWIKI 未上傳的立繪／命座／技能／素材圖示
- 簡體原文以 **OpenCC**（`cn → tw`）轉繁體
- 配裝推薦、畢業面板、有效詞條、定位、隊伍增益摘要、強度評級為**人工整理**，非官方資料

## 重新產生資料（版本更新時）

需要 Node 18+ 與網路。

```bash
cd tools && npm install
```

依序執行：

```bash
node scrape.mjs && node pageimgs2.mjs && node build.mjs && node fetch-images.mjs && node kuro-fill.mjs && node classify.mjs && node plan-data.mjs
```

- `scrape.mjs`　抓 BWIKI 的角色／武器／聲骸原始 wikitext → `raw.json`
- `pageimgs2.mjs`　解析每頁實際圖片檔名與 CDN 網址 → `filemap.json`／`pagemap.json`
- `build.mjs`　wikitext → 繁體 JSON，寫入 `../data/*.js`，並輸出待下載圖片清單
- `supp.mjs`　（選用）從 wuthering.gg 補 BWIKI 缺少的圖 → `supp.json`
- `fetch-images.mjs`　下載所有圖片到 `../assets/img/`（已存在的會略過）
- `kuro-fill.mjs`　用庫街區官方 API 補齊 BWIKI 缺的技能與突破素材
- `plan-data.mjs`　產生分階突破素材 → `../data/ascension.js`（角色取自庫街區、武器取自 BWIKI，並以總量表對帳校正）
- `classify.mjs`　由技能／命座／武器技能／套裝效果的文字推導可篩選的分類標籤（角色增益能力與傷害來源、武器功能效果、套裝件數與增益分類），**每次跑完 build 之後都要再跑這支**

`tools/` 只是產生資料用，網站本身不需要它，可以整個刪掉。

## 已知限制

- 3.6 之後的角色（清宵、景燃等）尚未收錄——BWIKI 的「共鳴者」分類還沒把它們加進去。
- 18 位較新角色的 BWIKI 只填了 Lv.1 基礎屬性，內頁會顯示 Lv.1 並註明；其餘 38 位顯示 Lv.90。
- 技能倍率表（各等級數值）未收錄，只有技能敘述。
- 「畢業面板」是依定位歸納的參考區間，不是官方數值。
