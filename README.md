# 鳴潮攻略站（本機網頁版）

版本基準：**3.5（2026-08）**　·　全繁體中文　·　純靜態，**所有圖片都已下載到本機，離線可用**。

## 怎麼開

直接用瀏覽器開 `index.html` 即可（資料用 `<script>` 載入，不是 `fetch`，所以 `file://` 也能跑）。

想用本機伺服器（行為最接近正式網站）：

```bash
node .claude/serve.js
```

然後開 http://localhost:8777

### 資料來源

- **鳴潮 BWIKI**（wiki.biligame.com）MediaWiki API — 主要來源：基本資料、基礎屬性、技能、共鳴鏈、突破素材、武器、聲骸
- **庫街區官方 WIKI**（api.kurobbs.com）— 補齊 BWIKI 缺的角色技能與突破素材；**配裝推薦（聲骸首位／毀業配裝／主副詞條／武器序列）也以官方為準**，42／56 位有官方資料，其餘 14 位沿用站方整理並在頁面標示
- **wuthering.gg** — 補齊 BWIKI 未上傳的立繪／命座／技能／素材圖示
- 簡體原文以 **OpenCC**（`cn → tw`）轉繁體
- 配裝推薦、畢業面板、有效詞條、定位、隊伍增益摘要、強度評級為**人工整理**，非官方資料

## 更新資料（出新角色／新武器／新聲骸時）

**直接在資料夾裡按兩下 `更新資料.bat` 就好**，不需要打指令。

它會自動：檢查 Node 是否安裝 → 第一次執行時裝相依套件 → 跑完整條資料管線 → 列出這次新增了什麼。整個過程約 3～8 分鐘。

- 新角色會**自動配到網址代號**（拼音），不用手動維護對照表
- 新武器、新聲骸、新套裝、新的官方配裝攻略都會一起抓進來
- 新角色若還沒有官方配裝或社群資料，系統會依技能文字推估定位／增益／畢業面板／詞條，並在頁面標「**系統推估**」
- 更新前會自動備份到 `data/_prev/`，出事把裡面的檔案複製回 `data/` 就還原
- 跑完在瀏覽器按 **Ctrl+F5** 才會看到新內容

另外附 `開啟網站.bat`，按兩下會起本機伺服器並開瀏覽器。

### 手動執行（進階）

需要 Node 18+ 與網路。

```bash
cd tools && npm install && node update.mjs
```

單獨跑某一步時，順序是：

```bash
node scrape.mjs && node pageimgs2.mjs && node build.mjs && node fetch-images.mjs && node supp.mjs && node fetch-images.mjs && node kuro-fill.mjs && node sonata-data.mjs && node plan-data.mjs && node kuro-recommend.mjs && node classify.mjs
```

- `scrape.mjs`　抓 BWIKI 的角色／武器／聲骸原始 wikitext → `raw.json`
- `pageimgs2.mjs`　解析每頁實際圖片檔名與 CDN 網址 → `filemap.json`／`pagemap.json`
- `build.mjs`　wikitext → 繁體 JSON，寫入 `../data/*.js`，並輸出待下載圖片清單
- `supp.mjs`　（選用）從 wuthering.gg 補 BWIKI 缺少的圖 → `supp.json`
- `fetch-images.mjs`　下載所有圖片到 `../assets/img/`（已存在的會略過）
- `kuro-fill.mjs`　用庫街區官方 API 補齊 BWIKI 缺的技能與突破素材
- `plan-data.mjs`　產生分階突破素材 → `../data/ascension.js`（角色取自庫街區、武器取自 BWIKI，並以總量表對帳校正）
- `kuro-recommend.mjs`　套用庫街區官方配裝推薦（含「聲骸首位推薦」＝主聲骸，會先從 `data/backup/` 還原再覆蓋，可重複執行）
- `ids.mjs`　角色代號對照（`ids.json`）；新角色用拼音自動產生代號，舊角色代號永不變動
- `sonata-data.mjs`　從鳴潮助手更新聲骸套裝合鳴效果，會自動收錄新套裝
- `classify.mjs`　由技能／命座／武器技能／套裝效果的文字推導可篩選的分類標籤（角色增益能力與傷害來源、武器功能效果、套裝件數與增益分類），**每次跑完 build 之後都要再跑這支**

`tools/` 只是產生資料用，網站本身不需要它，可以整個刪掉。

## 快速建立練度

不用一位一位點。到「我的角色」先用上方篩選縮小範圍（例如「5★」＋「冷凝」），按「**批次設定**」，勾要覆蓋的欄位再套用；沒勾的欄位維持原樣，所以可以分批處理。附「套用滿練預設」一鍵把 擁有／Lv90／技能10／聲骸+25／套裝與主聲骸 全部設好。

> 沒辦法用遊戲 UID 自動抓練度——鳴潮沒有角色櫥窗系統，庫街區的角色資料 API 也需要帳號存取令牌，不存在公開的 UID 查詢。

## 換裝置 / 多裝置

練度（我的角色、養成計劃、素材庫存）只存在**各裝置自己的瀏覽器**裡，網站沒有伺服器所以不會自動同步。

要搬到手機或另一台電腦：在「我的角色」或「養成計劃」頁按「**備份 · 換裝置同步**」→「複製代碼」→ 到新裝置的同一頁貼上 → 按「匯入」。也可以「下載成檔案」保存成 .json 備份。

注意：匯入會**覆蓋**該裝置原本的練度，不是合併。

## 已知限制

- 新角色若官方尚未公布配裝，主聲骸／套裝／詞條會是站方推估，頁面上會標示來源。
- 18 位較新角色的 BWIKI 只填了 Lv.1 基礎屬性，內頁會顯示 Lv.1 並註明；其餘 38 位顯示 Lv.90。
- 技能倍率表（各等級數值）未收錄，只有技能敘述。
- 「畢業面板」是依定位歸納的參考區間，不是官方數值。
- 配裝推薦有 14 位角色（菲比、卜靈、緋雪、達妮婭、漂泊者·氣動、露帕、卡提希婭、露西、琳奈、陸·赫斯、麗貝卡、洛瑟菈、贊妮、秧秧·玄翎）官方尚未公布，頁面會標「站方整理」，其主聲骸是依 COST 推斷、未必正確。
